# ARCADE CLASH

5명의 오리지널 캐릭터가 싸우는 2D 격투 게임 (HTML5 Canvas + Web Audio).

**플레이:** https://kyuil71.github.io/k-game01/

| 폴더 | 내용 |
|---|---|
| `index.html` | 게임 코드 |
| `sprites/` | 캐릭터 스프라이트 시트 |
| `portraits/` | 캐릭터 초상화 |
| `stages/` | 캐릭터별 홈 스테이지 배경 |
| `bgm/` | 캐릭터별 오케스트라 전투 테마 (반복 재생) |
| `voice/` | 캐릭터 기합·비명 및 아나운서 음성 |

이미지와 소리를 별도 파일로 불러오므로 파일을 직접 더블클릭하지 말고 웹 주소(GitHub Pages)로 접속해야 합니다.

## 조작 추가 기술 (전 캐릭터 공통)

| 기술 | 입력 |
|---|---|
| 스텝 잽 / 홉 킥(중단) | → + LP / → + LK |
| 해머 드롭(중단) / 라이징 킥(대공) | ← + HP / ← + HK |
| 라이징 어퍼 / 크러시 니 | 근접 HP / 근접 HK |
| 대시 스트라이크 / 플라잉 킥 | →→ 후 P / K |
| 다이브 킥 / 메테오 스매시 | 점프 중 ↓ + HK / ↓ + HP |
| 3단 연속기 | LP·LP·LP / LK·LK·LK (적중 시) |
| 강공격 연계 | HP→HP / HK→HK (적중 시) |
